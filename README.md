# Tic-Tac-Toe Robotic Arm

A Dobot Magician Lite robotic arm, programmed in Python, that uses OpenCV real-time color detection, contour analysis and centroid mapping to locate pieces on a physical board and play Tic-Tac-Toe autonomously. Stability timers, HSV threshold tuning and error handling make detection and play reliable.

Solo graduate project, Arizona State University, Fall 2025.

**Tools:** Python, OpenCV, NumPy, Dobot Magician Lite
